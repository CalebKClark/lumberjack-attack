# Changelog

## [0.11] — 2026-10-14

Godot 4 / C# port of the 0.1 playtest. Not a 0.2 content release.

- Rebuilt the homestead loop on Godot 4.7 and C#: chop, craft, place, fish, eat, sleep
- Fishing minigame, inventory, skills, collections, chests, and the wood chipper
- Named saves, load, and delete from the title screen
- Display and input settings
- Map files for the homestead, cabin, aspen forest, a cave, and a dungeon entrance
- World editor available from the title screen in this source tree
- Menu music carried over from 0.1

The Java/LibGDX project remains at tag `v0.1.0`.

## [0.1.0] — 2026-08-15

First playtest release (Java 17 / LibGDX).

- Foraging, fishing, sleeping to skip the day
- Energy and food
- Fishing minigame and 3 fish
- Cabin interior and homestead
- Pine trees
- Crafting: chest, wood chipper, compact pine wood, pine axe
- Inventory, skills, collections, stats
- Save / load / settings
- First song: "Lumberjack Attack Overture" plays in the menu
